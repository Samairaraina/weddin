Architecture Snapshot

WeddingBudget.ai Demo System

Frontend wizard + decor library on Vercel, FastAPI budget engine on Railway, SQLite persistence, and pre-seeded decor/narrative data to remove live CLIP and Gemini risk during judging.
Experience Layer

Frontend

  • React + Vite single-page app
  • Wizard, budget dashboard, decor library, RSVP, admin
  • `VITE_API_URL` points all hosted traffic to Railway
Output Layer

Deliverables

  • Budget range with section breakdowns
  • Scenario compare across hotel tiers
  • Planner narrative and PDF export
API Layer

FastAPI Backend

  • `/api/budget/*` for estimates, narratives, PDF
  • `/api/decor/*` for library and cost prediction
  • `/ping` health route for Railway checks
Data Layer

SQLite Store

  • Budget sessions and saved narratives
  • Decor images with stored 512-d embeddings
  • Artist, logistics, and F&B seed tables
Demo Safety

Pre-Seeded Intelligence

  • 400 Unsplash decor images embedded ahead of time
  • No live CLIP fetch required during decor prediction
  • 5 cached narratives unlocked by `USE_CACHED_NARRATIVE=true`
Optional Live Services

External Integrations

  • Unsplash only for the one-time seeding job
  • Gemini only when cached narratives are being generated
  • Hosted demo path can run without both once cached

Runtime flow

1. Wizard submit Vercel app sends normalized inputs to Railway FastAPI.
2. Budget engine FastAPI combines formulas with SQLite seed data and stores a session.
3. Decor predict Existing embedding is loaded from SQLite and passed to the cost model.
4. Output Frontend renders tabs, narrative, and downloadable PDF.
